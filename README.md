# Sinan Manna - Developer Portfolio & Resume Hub

A modern, responsive, high-performance developer portfolio website for **Sinan Manna**, Full Stack & Python Backend Developer based in Bengaluru, India.

## 🚀 Live Preview & Running Locally

### Option 1: Any Modern Web Browser
Simply double-click or open `index.html` in any browser (Chrome, Edge, Safari, Firefox).

### Option 2: Local HTTP Server (Python)
```bash
# Navigate to the portfolio folder
cd sinan-manna-portfolio

# Start a local static server
python -m http.server 8085
```
Then visit: `http://localhost:8085`

## 🌐 Deploy to GitHub Pages / Vercel / Netlify

1. **GitHub Pages**:
   - Push this directory to your GitHub repository `Sinxn51/sinan-manna-portfolio`.
   - Go to **Settings** > **Pages** > Set Source branch to `main` and folder to `/(root)`.
   
2. **Vercel or Netlify**:
   - Drag and drop this folder onto [Netlify Drop](https://app.netlify.com/drop) or link your GitHub repo in Vercel for instant free global CDN hosting.
